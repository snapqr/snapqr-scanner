# SnapQR

**Free QR code scanner & generator that runs entirely in your browser: [snapqr.org](https://snapqr.org)**

- **Scan** a QR code from a photo, a screenshot (Ctrl+V) or your camera, and see the real link before you open it.
- **Create** QR codes for links, WiFi, vCards, WhatsApp, email, SMS and phone, with your colors and logo. PNG, SVG or PDF.
- **Private by design:** nothing you type or scan is uploaded. No signup, no watermark, and codes never expire.

Built with Next.js, decoded with [ZXing](https://github.com/zxing-cpp/zxing-cpp) in a Web Worker. Every change is round-trip tested: each generated code is rendered, downloaded and decoded again.

Available in English, [Tiếng Việt](https://snapqr.org/vi) and [Español](https://snapqr.org/es).
